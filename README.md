# DOOM for Besta RTOS

將 DOOM 移植至 Besta RTOS 的實驗性版本，以 [PureDOOM](https://github.com/Daivuk/PureDOOM) 作為遊戲核心。

> **專案狀態：實驗性／尚不穩定**
> 本移植版本目前可以進入遊戲並進行操作，但仍存在多項已知問題，請於使用前詳閱下列說明。

## 專案簡介

本專案以 Project-muteki 與 PureDOOM 單一標頭檔實作為基礎，將 DOOM 移植至 Besta RTOS 環境執行。目前已具備基本的畫面輸出與鍵盤輸入，遊戲流程可正常進行，但畫面顯示、按鍵對應與操作手感仍有待改善。

## 檔案說明

| 檔案 | 說明 |
| --- | --- |
| `main.c` | 主程式，負責初始化、主迴圈、畫面輸出與輸入處理 |
| `press_table.c` | 按鍵狀態表，用以處理按鍵放開事件的偵測問題 |
| `PureDOOM.h` | PureDOOM 原始版本標頭檔 |
| `PureDOOM_modified.h` | 修改版 PureDOOM 標頭檔，用以解決 Newlib 環境下的編譯錯誤 |
| `build.bat` | 一鍵編譯腳本 |

## 編譯方式

於專案根目錄執行：

```bat
build.bat
```

> 編譯前請確認工具鏈（含 Newlib）已正確安裝，並可於命令列中呼叫。
> 若遇到與 Newlib 相關的編譯錯誤，請確認使用的是 `PureDOOM_modified.h` 而非原始的 `PureDOOM.h`。

## 已知問題

1. **存在 `.doomrc` 時程式卡死**
   若執行目錄下存在 `.doomrc` 檔案，程式會進入無窮迴圈（`while (true)`）而無回應。目前尚未找出根本原因。
   - 暫時解法：執行前請確認當前目錄下**不存在** `.doomrc`。

2. **畫面僅顯示上半部**
   實際輸出的畫面只涵蓋螢幕上半部分，疑似存在非法記憶體存取，但尚未於程式碼中定位到問題。

3. **按鍵對應異常**
   部分按鍵的對應結果與預期不符，原因尚待查明。

4. **操作手感不佳**
   輸入響應與操控手感不理想，但整體仍可進行遊玩。

## 尚未實作的功能

- **音效**：尚未支援。實作上需處理多執行緒與 MIDI 解碼，目前暫無實作計畫。
